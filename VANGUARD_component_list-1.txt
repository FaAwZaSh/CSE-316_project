====================================================================
BUILD SIMULATION — walking the project start to finish
====================================================================
I mentally built this in order (power → MCU → sensing → actuation →
wireless → warning → enclosure) to check nothing was missing. Three
real gaps turned up that weren't obvious from the proposal text alone:

1. BADGE-SIDE LEVEL SHIFTING: The proposal only discusses 3.3V
   level shifting for the MAIN station's VL53L0X/nRF24L01+. But the
   wearable badge ALSO has a 5V Nano talking SPI to a 3.3V nRF24 —
   same problem, different location. Fixed with the 220Ω series
   resistors in Section 5 (cheaper than a full level shifter for a
   low-speed link like this) + powering that nRF24 off the Nano's
   onboard 3.3V pin.

2. CURRENT BUDGET ON THE MAIN ADAPTER: Doing the math on staggered
   MG996R stall current (~2.5A) + logic + strobe/buzzer pushed me to
   bump the adapter and fuse from a "safe-sounding" 2A/1A to 3A/3A.
   An undersized adapter here would brown out mid-slew.

3. POWER DISTRIBUTION HARDWARE: The proposal's "common ground"
   design note has no corresponding purchasable part in the original
   component table — you'd hit this gap only once you're literally
   staring at 6+ modules needing a shared 5V/6V/GND point. Added
   screw terminal blocks (Section 10) to solve it cleanly instead of
   twisting jumper wires together.

Everything else in the block diagram / pinout map (PIR→INT0/1/2,
I2C bus, SPI bus + CS lines, PWM→servos, GPIO→MOSFET) maps directly
onto components already in Sections 1-9 above — nothing else was
missing in the simulation.
